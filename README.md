
# Qazaq Trails

An Interactive Travel Guide to Kazakhstan

## About the Project

Qazaq Trails is an interactive and responsive travel website that helps users discover Kazakhstan, explore tourist destinations, save favorite places and plan their trips.

This website was developed as a final project for the Web Technologies 1 course at Astana IT University.

## Main Features

- 12 tourist destinations in Kazakhstan
- Dynamic search, filtering and sorting
- Destination details
- Favorites management
- Interactive trip planner
- Travel budget calculator
- Save, edit and delete trips
- Feedback form with validation
- Responsive design

## How to Run

1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Install the Live Server extension.
4. Open index.html with Live Server.

## Project Notes

Travel prices and destination ratings are illustrative.
User preferences, favorites, trips and feedback are stored locally in the browser.
